# Urban Realty Monorepo

Projects:
- `server` (Node.js/Express)
- `client` (React + Vite)
- `mobile` (Flutter)

Quick Start:
- Client: `cd client && npm ci && npm run dev`
- Server: Requires environment variables (see `.env.example`), then `npm start`
- Mobile: Requires Flutter SDK; see `mobile/` README
